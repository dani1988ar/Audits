    📡 Use on Phone via WiFi
    Run a local server on your PC then open the address on your phone while on the same WiFi network.
    Step 1 — Open Command Prompt in the folder where PM Audit.html is saved
    Step 2 — Run:  python -m http.server 8080
    Step 3 — Find PC's IP: run ipconfig → look for IPv4 Address
    Step 4 — On phone browser: http://[PC-IP]:8080/PM%20Audit.html
    To install on phone home screen: open in Safari (iOS) → Share → Add to Home Screen. On Android Chrome → menu → Add to Home Screen.
